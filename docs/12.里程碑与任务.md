# 12. 里程碑与任务

## 1. 目标

第一个目标：功能对齐老版。范围以 `2.产品需求` 为准，老版只作为行为参考，不抄老版代码。

功能对照覆盖：

- 朋友与人格
- 聊天
- 记忆
- 日程
- 语音
- 图片与视觉
- 知识库与文件
- 搜索与看屏
- 想法与表达学习
- 立绘、Live2D、沉浸模式、桌宠
- 生活线
- 手机与多端
- 生态同步
- 设置与维护

## 2. 顺序

0. 功能对照
1. 工程底座
2. yumeCore 最小闭环
3. 电脑端竖切
4. 电脑端功能对齐
5. Android 功能对齐
6. 同步
7. 主动生活
8. 打包发布

每个阶段结束都必须能运行，不把问题堆到最后。

### 老版差异与缺口

- 老版有游戏模式和小世界，`2.产品需求` 未列入新版范围，暂不实现。
- 老版有 `friend_episodes` 情节记忆、回收站恢复和 normal / roleplay / tool 模式，新数据模型和接口未定义，暂不迁移。
- 老版手机是 WebView + Chaquopy，新版改为 Kotlin + Compose + yumeCore；旧手机实现不沿用。
- 老版手机不能编辑或删除旧记忆，新版按 `2.产品需求` 放开。
- 老版同步用 UDP 48000 + 6 位临时码，新版按 `14.生态协作协议` 用 mDNS、配对密钥和模块授权。
- 老版主题是浅色 / 深色 / 跟随系统，新版是纸 / 苔 / 茶 / 樱 × 浅 / 深。
- 搜索、看屏、文件操作、语音目前没有独立数据表；实现前需在模块清单里确认模块 ID 和能力声明。

验收：每个功能都有落点和验收标准。
