# 01 项目定位

yumeFriend 是一个个人使用、本地优先的 AI 朋友系统。

用户创建多个有独立人格和记忆的朋友，和他们长期聊天、相处。

聊天、记忆、生活线是核心。语音、立绘、桌宠、日程都是朋友的能力和呈现方式。

每个同系列产品内置同一套 yumeCore，可以独立运行，也能发现彼此、共享朋友和记忆。

数据默认保存在用户自己的设备上，不依赖公共平台。

它不是社交软件，不是通用聊天工具，也不是公共平台。

# 02 产品需求

## 1. 用户

单个用户，在自己的电脑或设备上使用，可以同时使用多个同系列产品。

## 2. 核心对象

- **朋友**：人格、外观、声音、关系状态
- **对话**：每个朋友一条连续会话
- **消息**：用户说的话、朋友说的话、系统事件
- **记忆**：长期事实、偏好、约定、经历
- **日程**：提醒、待办、计划
- **活动**：生活线里发生的事
- **同系列产品**：可以被发现、被授权共享数据的产品

## 3. 功能需求

| 模块 | 需求 |
|---|---|
| 朋友与人格 | 创建、编辑、删除多个朋友；人格由用户自由填写；朋友之间数据完全隔离 |
| 聊天 | 流式回复、历史记录、停止生成、错误提示、重新发送；聊天中显示朋友头像，自己的消息不显示头像 |
| 记忆 | 自动保存、手动添加、编辑、删除、回忆，并注入上下文 |
| 日程提醒 | 新建、修改、删除、到点提醒、完成记录 |
| 语音 | 语音合成、语音输入、语音通话，音色可配置 |
| 图片与视觉 | 发图、看图、画图、保存图片 |
| 知识库与文件 | 上传文档、检索内容、浏览文件、受控修改文件 |
| 搜索与看屏 | 联网搜索、手动截屏并理解 |
| 想法与表达学习 | 小纸条、说话风格、表达样本、回滚 |
| 立绘与呈现 | 立绘、Live2D、沉浸模式、桌宠 |
| 外观与主题 | 浅色/深色切换；颜色主题纸、苔、茶、樱；每个颜色有深浅两套；右上角三点切换 |
| 生活线与主动分享 | 朋友自己的活动状态、真实活动记录、主动分享；活动必须有真实结果 |
| 手机与多端 | Android 手机独立运行，平板同一 APK 适配；手机和电脑各自本地保存；设备间同步；不强制服务器 |
| 手机端范围 | 首期支持聊天、记忆、日程、语音、知识库、主题、沉浸模式；桌宠、看屏、电脑文件操作留在桌面端 |
| 生态同步 | 发现同系列产品，经用户同意后共享朋友、记忆、日程和事件；支持自动同步和手动同步 |
| 设置与维护 | 模型配置、功能开关、主题、更新、日志 |
