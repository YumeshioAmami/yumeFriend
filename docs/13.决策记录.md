# 13. 决策记录

日期：2026-11-22

规则：新决策追加，不覆盖旧决策。文档冲突时，以本文最新条目为准，并同步修正对应文档。

## 架构

- yumeCore 独立仓库、独立版本，Kotlin Multiplatform，目标桌面 JVM / Android。
- yumeCore 无界面、无业务模块、不拥有数据。
- 模块清单声明表、数据位置、同步范围；yumeCore 只提供通用读写、事件、同步、授权、发现、模块生命周期。
- 产品固定 yumeCore 版本，不修改 yumeCore 源码。
- 电脑端：Electron + React + Python；Python 通过本机 HTTP / WebSocket 调 yumeCore。
- Android：Kotlin + Compose，直接嵌入 yumeCore。
- 同步支持局域网直连和服务器，使用同一套协议。
- 不同产品可以使用不同数据库，通过适配器映射成同一份逻辑数据；同步不传数据库文件。
- 服务器原生部署，systemd 管理 yumeCore 服务进程，只做同步和附件存储。

## 数据与接口

- 数据模型以 `5.数据模型` 为准；模块 ID 见 `5.1.1`。
- 同步、授权、删除记录、待同步改动、冲突记录都带 `module_id`。
- 接口分三块：yumeCore、电脑端、手机端，见 `6.接口文档`。
- 手机端接口是 Kotlin 接口，不走本机 HTTP。
- `assets` 走附件通道；`voices`、`embeddings`、`module_registry` 只存本机。

## 产品与范围

- 第一目标：按 `2.产品需求` 对齐老版功能。老版只作为行为参考，不抄老版代码。
- 主动生活是核心体验，见 `10.主动生活`。
- 手机端首期只接收主动分享，不运行生活线引擎。
- 主题：纸 / 苔 / 茶 / 樱 × 浅 / 深。
- 电脑端主题在右上角三个点；手机端主题在 `设置 → 主题`。
- 电脑端布局：顶栏 + 左侧朋友栏 + 中间聊天。
- 手机端布局：朋友页 + 全屏聊天页，底部导航为朋友 / 日程 / 设置。
- 朋友头像显示在聊天消息左侧；自己的消息不显示头像。
- 双方都用笔记式排版，不用气泡。

## 提示词

- 提示词结构以 `8.提示词与人格` 为准。
- 人格只写她是谁；记忆、状态、表达样本各放对应块。
- 提示词只负责人格和上下文。
- `max_tokens` 默认 `null`，由适配器按模型默认值或最大输出处理。

## 发布

- 数据、日志、媒体统一放程序旁的 `user_data/`。
- 电脑端安装时由用户选择目录。
- 电脑端：electron-builder + NSIS，自动更新用 `latest.yml`。
- Android：Gradle 输出 APK，自有更新清单 `latest.json`。
- 服务器：原生部署，数据目录 `/srv/yumefriend/data`，token 用环境变量。
- 应用版本、yumeCore 版本、协议版本分开。

## 开发

- 文档先行、单一事实源、一次只改一件事。
- 改模块时同步更新模块清单、数据模型、接口、提示词、前端设计。
- yumeCore 只放运行时；产品名、业务逻辑、界面放产品。
- AI 默认只在聊天里生成内容，明确要求时才写入文件。
- 旧版只用于确认行为，不作为实现参考。

## 生态协作

- 生态协作协议 v1.0 生效，`protocol_version=1`，以 `14.生态协作协议` 为准。
- 局域网用 mDNS `_yumecore._tcp.local` 发现；配对经用户确认，双方保存 `pair_secret`；对端请求带 `X-YF-Peer-Token`。
- `peers.pair_secret` 仅本机保存，不参与同步。
- 授权 `write` 包含 `read`；`resource_id` 按 `friend_id` 解释。
- 同时间戳但数据不同时写入 `sync_conflicts`，保留本地，不自动覆盖。
- 局域网对端接口为 `/peer/v1`，服务器同步接口为 `/server-sync/v1`。

## 仓库

- yumeCore 独立仓库、独立版本；yumeFriend 电脑端和 Android 同属一个产品仓库。
- 两个仓库都开源。
- 产品仓库目录为 `desktop/`、`android/`、`docs/`；yumeCore 仓库根目录为 Gradle 工程。
- 初始版本：yumeFriend `0.1.0`，yumeCore `0.1.0`；协议版本保持 `1`。
- 代码许可证沿用旧版决定：Apache-2.0。
- 阶段 1 固定版本以 `4.技术栈` 的版本表为准。
