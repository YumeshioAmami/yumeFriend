# yumeFriend 前端设计

## 1. 电脑端布局

顶栏 + 左侧朋友栏 + 中间聊天。

记忆、日程、知识使用弹窗或右侧抽屉，不常驻。

聊天页顶部放“人格 / 记忆 / 日程 / 知识 / 生活”，以及独立的“沉浸 / 桌宠”模式入口。

左侧朋友栏可收起；右侧抽屉只显示当前功能，不再重复顶部功能选择。

朋友头像显示在左侧朋友栏和聊天消息左侧；人格页可上传头像、修改名字 / 人格 / 补充要求、切换在场开关、删除朋友；删除前确认。

左侧朋友栏显示未读数；打开该朋友聊天后清零。主动消息和日程提醒未读时显示角标。

聊天内容宽度随窗口自适应；输入框使用透明底，不出现大块白底。

生成中可停止；错误或未完成的消息可重试；来源和工具记录显示在消息正文下方。

聊天默认加载最近 200 条；有更早历史时顶部显示“加载更早”。

想法并入日程；文件并入知识；风格和呈现设置并入人格。搜索、看屏作为内置能力，不占顶部入口。

人格里的呈现只配置外观；沉浸和桌宠是独立模式，不放在人格设置里。

沉浸模式：整屏外观 + 背景，底部单个对话框；按情绪单元分段推进，点到哪个单元就切哪个情绪；轮到用户时同一框变输入；可退出。顶部提供“调整立绘”：拖动改变位置，滚轮或 ± 缩放，复位；Live2D 和立绘都生效，按朋友保存。

桌宠：真正透明置顶小窗；用系统窗口拖动角色，窗口位置和缩放存 `user_data/pet_window.json`，缩放上限 540%。角色填满窗口；透明空白区域鼠标穿透，只有角色和 UI 区域接收鼠标。操作按钮竖向排列成一个左侧矩形，鼠标悬停才显示，包括主界面、换朋友、说话、锁定、静音、±、位置、关闭；位置模式下拖动角色可调整窗口内偏移，偏移存本机 `yf.pet.offset`。锁定后同一位置只显示解锁。新回复自动出现一次，12 秒后隐藏，悬停不会重新显示；点“说话”才显示统一聊天面板，面板内显示最新回复和输入框共用一个框；点击回复文字推进下一段。锁定只禁止拖动和交互，不禁止主动消息显示和语音播放。与沉浸共用外观包和情绪单元。老版托盘菜单和游戏管理不做。

设置里的 Live2D 区域：显示运行时状态、两份官方协议链接、同意勾选和下载按钮；从 Live2D 官方 5.2 Core 地址下载，下载完成无需刷新即可重试渲染。

默认外观统一为 YUI：Live2D 用 YUI 模型，立绘用同一模型渲染的全身透明图；两者按 Apache-2.0 分发，不内置无授权大肥鱼资产。

普通聊天不显示立绘/Live2D，也不使用情绪；情绪只供沉浸和桌宠使用。

进入沉浸或桌宠时，前端对最新一条已完成的回复按需请求情绪分类；普通聊天不提前分类。分类结果缓存到该消息，重复进入不重复调用。

设置里的 Live2D 模型页参照老版工作台：左侧模型列表，中间实时预览，右侧标签编辑。模型列表显示内置 YUI 和 `user_data/live2d/` 内的本机模型，同一 moc3 只列一次，并显示被哪些朋友使用。

标签可新增、改名、删除，不能删除默认标签；每个标签可勾选 `.exp3.json` 表情、调基础参数和高级参数，也可以把当前预览定格成该标签；保存到模型级设置文件。首版只设置已有模型，不做模型导入。

呈现设置里的立绘包不编辑标签：标签直接取包内图片文件名，按文件名排序展示。

设置页语音区域：TTS / STT 分别配置 `base_url`、`api_key`、`model`；音色列表可新建、编辑、删除和试听。

人格页声音区域：选择当前音色，开关“回复默认带语音”。开启后回复完成时按气泡逐段合成并依次播放；消息下方提供播放 / 停止按钮。

聊天输入栏提供通话按钮。通话为半双工：按住说话，松开后识别并发送；回复完成时播放语音，不依赖“回复默认带语音”开关；播放和生成期间不能录音；可挂断。

设置页采用左侧分页：模型 / 外观 / 语音 / 视觉 / 同步 / 功能 / 更新 / 关于。模型页使用独立卡片，显示聊天模型说明、服务地址、密钥、模型名和“测试连接”；不再把所有配置堆在一个长表单里。

设置页外观区域提供缩放选择 80% / 90% / 100% / 110% / 120%；语音页提供语音保留天数，默认 30 天。

设置页更新区域按“检查更新 → 下载更新 → 安装并重启”推进，下载时显示进度。

设置页提供“法律说明”入口，集中展示项目协议、YUI 资产来源、Live2D 官方协议和第三方依赖清单入口。

## 2. 聊天

朋友头像 28–30px，放在消息左侧。

自己的消息不显示头像。

双方都用笔记式排版，不用气泡。

时间用数字，例如 `2026-11-21 22:00`。

## 3. 电脑端主题

右上角三个点：

1. 浅色模式
2. 深色模式
3. 颜色选择弹窗

颜色：纸、苔、茶、樱。

每个颜色都有浅色和深色两套。

弹窗使用不透明背景。

## 4. 电脑端其他

输入栏使用加号、图片、麦克风小图标。

消息附件直接显示在正文下方；语音提供播放按钮，图片按原比例显示。

左下角只保留“设置 / 全屏”。

不保留“模块”入口。

## 5. 手机端

手机端用单栏布局，底部导航：朋友 / 日程 / 设置。

手机端沿用电脑端的纸 / 苔 / 茶 / 樱配色和视觉语言：细边框、笔记式消息、朋友列表不使用卡片，头像圆框、正文留白和顶部功能文字链接与电脑端一致。

朋友页是默认页；点一个朋友进入全屏聊天页。

聊天页没有底部导航。顶部第一行是返回、朋友头像、名字、状态；第二行是“记忆 / 人格 / 日程 / 知识 / 语音 / 沉浸”。下方是消息和输入栏。底栏使用麦克风、通话、发送等小图标，输入区为透明或轻底色的圆角输入框。

顶部不显示品牌栏和主题点。

主题放在 `设置 → 主题`：浅色 / 深色，颜色纸 / 苔 / 茶 / 樱。

记忆、知识使用抽屉或全屏页。

朋友列表显示未读角标，打开聊天后清零。聊天默认加载最近 200 条，顶部可加载更早历史；生成中提供停止，已生成正文保留为 `partial`；错误或未完成回复可重试。普通聊天按 `<<<MSG>>>` 分段显示正文，不显示情绪；来源和工具记录显示在正文下方。

日程到点使用系统通知提醒，同时写入 `system` / `notice` 消息和 `schedule_events`，提醒进入未读；只处理带 `time_local` 的待办。

设置页语音区域列出 Android 系统 TTS 音色，可保存到本机音色表；人格页声音区域选择当前音色并开关“回复默认带语音”。聊天播放时使用朋友绑定的系统音色，未绑定使用系统默认音色。

人格页头像支持上传图片，图片存本机附件目录并写朋友的 `avatar_asset_id`；朋友列表、聊天顶部和助手消息使用真实头像，没有图片时回退名字首字。

知识导入支持 txt / md / pdf / docx；抽取全文后按 800 字、重叠 100 字切片，PDF 用 PDFBox-Android，docx 读取 `word/document.xml`。

记忆页支持手动增删改和按关键词回忆；回复后自动提取长期记忆并留改动记录。

聊天输入栏提供通话按钮。通话为半双工：按住说话，松开后识别并发送；回复完成时按气泡逐段播放语音，不依赖“回复默认带语音”开关；生成和播放期间不能录音；可挂断。

人格页的“呈现”区域列出 YUI 立绘和 YUI Live2D，保存朋友的 `visual_mode` 与 `visual_pack_id`；沉浸模式只显示所选立绘或 Live2D，不再使用头像充当立绘。

手机沉浸模式：全屏黑色背景，显示所选立绘或 Live2D；底部单个对话框。她的话按 `segments_json` 或空行分段点击推进，点完后同一框切换为输入；可退出；支持横竖屏切换，横屏时立绘和对话区自适应。回复完成播放语音。Live2D Core 缺失时提示去设置下载并回退到立绘预览。

设置页“功能”区域提供记忆、日程提醒、语音、知识库四个开关，默认开启；关闭后隐藏对应入口并停用相应能力。设置页“日志”区域显示最近 200 行本机日志，可清空。

设置页 Live2D 区域显示运行库状态、两份官方协议链接、同意勾选和下载按钮；下载完成即可在沉浸模式加载 Live2D。

设置页更新区域填写 `latest.json` 地址，按“检查更新 → 下载 → 安装”推进；清单版本号高于当前 APK 时显示下载按钮。

设置页同步区域：允许其他设备配对、发现设备、已配对设备、模块授权、局域网同步、服务器地址与 token、服务器同步、冲突数量；发现为空时提供手动地址和端口。

手机端首期只做聊天、记忆、日程、语音、知识库、主题、沉浸；桌宠、看屏、电脑文件操作留在桌面端。
