# yumeFriend 前端设计

## 1. 电脑端布局

顶栏 + 左侧朋友栏 + 中间聊天。

记忆、日程、知识使用弹窗或右侧抽屉，不常驻。

聊天页顶部放“人格 / 记忆 / 日程 / 知识 / 生活”，以及独立的“沉浸 / 桌宠”模式入口。

左侧朋友栏可收起；右侧抽屉只显示当前功能，不再重复顶部功能选择。

聊天内容宽度随窗口自适应；输入框使用透明底，不出现大块白底。

想法并入日程；文件并入知识；风格和呈现设置并入人格。搜索、看屏作为内置能力，不占顶部入口。

人格里的呈现只配置外观；沉浸和桌宠是独立模式，不放在人格设置里。

沉浸模式：整屏外观 + 背景，底部单个对话框；按情绪单元分段推进，点到哪个单元就切哪个情绪；轮到用户时同一框变输入；可退出。

桌宠：透明置顶小窗，可拖动；与沉浸共用同一外观包和情绪单元，显示最新回复气泡和输入栏；提供回主界面、关闭。

设置里的 Live2D 区域：显示运行时状态、两份官方协议链接、同意勾选和下载按钮；下载完成无需刷新即可重试渲染。

默认外观统一为 YUI：Live2D 用 YUI 模型，立绘用同一模型渲染的全身透明图；两者按 Apache-2.0 分发，不内置无授权大肥鱼资产。

普通聊天不显示立绘/Live2D，也不使用情绪；情绪只供沉浸和桌宠使用。

进入沉浸或桌宠时，前端对最新一条已完成的回复按需请求情绪分类；普通聊天不提前分类。分类结果缓存到该消息，重复进入不重复调用。

设置里的 Live2D 模型页：选择模型后编辑该模型的标签列表、默认标签、每个标签绑定的表情和参数；同一模型被多个朋友使用时共享这套标签。

呈现设置里的立绘包不编辑标签：标签直接取包内图片文件名，按文件名排序展示。

## 2. 聊天

朋友头像 28–30px，放在消息左侧。

自己的消息不显示头像。

双方都用笔记式排版，不用气泡。

时间用数字，例如 `2026-11-21 22:00`。

## 3. 电脑端主题

右上角三个点：

1. 浅色模式
2. 深色模式
3. 颜色选择弹窗

颜色：纸、苔、茶、樱。

每个颜色都有浅色和深色两套。

弹窗使用不透明背景。

## 4. 电脑端其他

输入栏使用加号、图片、麦克风小图标。

消息附件直接显示在正文下方；语音提供播放按钮，图片按原比例显示。

左下角只保留“设置 / 全屏”。

不保留“模块”入口。

## 5. 手机端

手机端用单栏布局，底部导航：朋友 / 日程 / 设置。

朋友页是默认页；点一个朋友进入全屏聊天页。

聊天页没有底部导航。顶部第一行是返回、朋友头像、名字、状态、更多；第二行是“记忆 / 人格 / 日程 / 知识 / 语音 / 沉浸”。下方是消息和输入栏。

顶部不显示品牌栏和主题点。

主题放在 `设置 → 主题`：浅色 / 深色，颜色纸 / 苔 / 茶 / 樱。

记忆、知识使用抽屉或全屏页。

手机端首期只做聊天、记忆、日程、语音、知识库、主题；桌宠、看屏、电脑文件操作留在桌面端。
