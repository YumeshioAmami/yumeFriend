# yumeFriend 前端设计

## 1. 电脑端布局

顶栏 + 左侧朋友栏 + 中间聊天。

记忆、日程、知识使用弹窗或右侧抽屉，不常驻。

聊天页顶部放“人格 / 记忆 / 日程 / 知识 / 生活”，以及独立的“沉浸 / 桌宠”模式入口。

左侧朋友栏可收起；右侧抽屉只显示当前功能，不再重复顶部功能选择。

朋友头像显示在左侧朋友栏和聊天消息左侧；人格页可上传头像、修改名字 / 人格 / 补充要求、切换在场开关、删除朋友；删除前确认。

左侧朋友栏显示未读数；打开该朋友聊天后清零。主动消息和日程提醒未读时显示角标。

聊天内容宽度随窗口自适应；输入框使用透明底，不出现大块白底。

生成中可停止；错误或未完成的消息可重试；来源和工具记录显示在消息正文下方。

想法并入日程；文件并入知识；风格和呈现设置并入人格。搜索、看屏作为内置能力，不占顶部入口。

人格里的呈现只配置外观；沉浸和桌宠是独立模式，不放在人格设置里。

沉浸模式：整屏外观 + 背景，底部单个对话框；按情绪单元分段推进，点到哪个单元就切哪个情绪；轮到用户时同一框变输入；可退出。顶部提供“调整立绘”：拖动改变位置，滚轮或 ± 缩放，复位；Live2D 和立绘都生效，按朋友保存。

桌宠：真正透明置顶小窗，只显示角色和悬浮 UI；用系统窗口拖动角色，± 缩放角色，位置和缩放存 `user_data/pet_window.json`。气泡和输入栏固定在上方头部区域，悬停只显示内容、不改变角色大小。悬浮显示主界面、换朋友、锁定、静音、下一句、关闭；点击气泡或“下一句”推进回复，输入栏可发送。与沉浸共用外观包和情绪单元，有语音时播放。锁定后只保留解锁。老版托盘菜单和游戏管理不做。

设置里的 Live2D 区域：显示运行时状态、两份官方协议链接、同意勾选和下载按钮；从 Live2D 官方 5.2 Core 地址下载，下载完成无需刷新即可重试渲染。

默认外观统一为 YUI：Live2D 用 YUI 模型，立绘用同一模型渲染的全身透明图；两者按 Apache-2.0 分发，不内置无授权大肥鱼资产。

普通聊天不显示立绘/Live2D，也不使用情绪；情绪只供沉浸和桌宠使用。

进入沉浸或桌宠时，前端对最新一条已完成的回复按需请求情绪分类；普通聊天不提前分类。分类结果缓存到该消息，重复进入不重复调用。

设置里的 Live2D 模型页参照老版工作台：左侧模型列表，中间实时预览，右侧标签编辑。模型列表显示内置 YUI 和 `user_data/live2d/` 内的本机模型，同一 moc3 只列一次，并显示被哪些朋友使用。

标签可新增、改名、删除，不能删除默认标签；每个标签可勾选 `.exp3.json` 表情、调基础参数和高级参数，也可以把当前预览定格成该标签；保存到模型级设置文件。首版只设置已有模型，不做模型导入。

呈现设置里的立绘包不编辑标签：标签直接取包内图片文件名，按文件名排序展示。

设置页语音区域：TTS / STT 分别配置 `base_url`、`api_key`、`model`；音色列表可新建、编辑、删除和试听。

人格页声音区域：选择当前音色，开关“回复默认带语音”。开启后回复完成时按气泡逐段合成并依次播放；消息下方提供播放 / 停止按钮。

聊天输入栏提供通话按钮。通话为半双工：按住说话，松开后识别并发送；回复完成时播放语音，不依赖“回复默认带语音”开关；播放和生成期间不能录音；可挂断。

设置页模型区域提供“测试模型”按钮，使用当前表单里的地址、Key 和模型发一条测试请求并显示回复。

设置页界面区域提供缩放选择 80% / 90% / 100% / 110% / 120% 和语音保留天数，默认 30 天。

设置页更新区域按“检查更新 → 下载更新 → 安装并重启”推进，下载时显示进度。

设置页提供“法律说明”入口，集中展示项目协议、YUI 资产来源、Live2D 官方协议和第三方依赖清单入口。

## 2. 聊天

朋友头像 28–30px，放在消息左侧。

自己的消息不显示头像。

双方都用笔记式排版，不用气泡。

时间用数字，例如 `2026-11-21 22:00`。

## 3. 电脑端主题

右上角三个点：

1. 浅色模式
2. 深色模式
3. 颜色选择弹窗

颜色：纸、苔、茶、樱。

每个颜色都有浅色和深色两套。

弹窗使用不透明背景。

## 4. 电脑端其他

输入栏使用加号、图片、麦克风小图标。

消息附件直接显示在正文下方；语音提供播放按钮，图片按原比例显示。

左下角只保留“设置 / 全屏”。

不保留“模块”入口。

## 5. 手机端

手机端用单栏布局，底部导航：朋友 / 日程 / 设置。

朋友页是默认页；点一个朋友进入全屏聊天页。

聊天页没有底部导航。顶部第一行是返回、朋友头像、名字、状态、更多；第二行是“记忆 / 人格 / 日程 / 知识 / 语音 / 沉浸”。下方是消息和输入栏。

顶部不显示品牌栏和主题点。

主题放在 `设置 → 主题`：浅色 / 深色，颜色纸 / 苔 / 茶 / 樱。

记忆、知识使用抽屉或全屏页。

手机端首期只做聊天、记忆、日程、语音、知识库、主题；桌宠、看屏、电脑文件操作留在桌面端。
