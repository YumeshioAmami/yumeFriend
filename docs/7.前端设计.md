# yumeFriend 前端设计

## 1. 电脑端布局

顶栏 + 左侧朋友栏 + 中间聊天。

记忆、日程、知识使用弹窗或右侧抽屉，不常驻。

聊天页顶部放“记忆 / 日程 / 想法 / 风格”入口，内容使用右侧抽屉。

## 2. 聊天

朋友头像 28–30px，放在消息左侧。

自己的消息不显示头像。

双方都用笔记式排版，不用气泡。

时间用数字，例如 `2026-11-21 22:00`。

## 3. 电脑端主题

右上角三个点：

1. 浅色模式
2. 深色模式
3. 颜色选择弹窗

颜色：纸、苔、茶、樱。

每个颜色都有浅色和深色两套。

弹窗使用不透明背景。

## 4. 电脑端其他

输入栏使用加号、图片、麦克风小图标。

左下角只保留“设置 / 全屏”。

不保留“模块”入口。

## 5. 手机端

手机端用单栏布局，底部导航：朋友 / 日程 / 设置。

朋友页是默认页；点一个朋友进入全屏聊天页。

聊天页没有底部导航。顶部第一行是返回、朋友头像、名字、状态、更多；第二行是“记忆 / 人格 / 日程 / 知识 / 语音 / 沉浸”。下方是消息和输入栏。

顶部不显示品牌栏和主题点。

主题放在 `设置 → 主题`：浅色 / 深色，颜色纸 / 苔 / 茶 / 樱。

记忆、知识使用抽屉或全屏页。

手机端首期只做聊天、记忆、日程、语音、知识库、主题；桌宠、看屏、电脑文件操作留在桌面端。
