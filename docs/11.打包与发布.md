# 11. 打包与发布

## 1. 版本

- 应用版本、yumeCore 版本、协议版本分开。
- 应用和 yumeCore 用语义化版本，协议版本用整数。

## 2. 运行

- 电脑启动顺序：Electron → yumeCore → Python → React。
- yumeCore 检查数据库并执行迁移。
- 迁移前备份到 `user_data/backups/`。
- 数据库、日志、媒体统一放 `user_data/`。
- Android 直接嵌入 yumeCore，启动时检查数据库并执行迁移。

## 3. yumeCore 发布

- 独立仓库、独立版本、独立标签。
- 发布 JVM / Android 制品。
- 产品固定版本引入。

## 4. 电脑端打包

- 前端：Vite 构建。
- Python：PyInstaller。
- yumeCore：Gradle 构建 JVM 制品。
- 安装包：electron-builder + NSIS。
- 安装时让用户选择目录，`user_data` 放在安装目录旁。
- 安装包包含 Electron / React / Python / yumeCore。
- 自动更新：electron-updater + `latest.yml`。

## 5. Android 打包

- Kotlin + Compose Multiplatform。
- Gradle 输出 APK。
- yumeCore 直接嵌入。
- 自有更新清单 `latest.json` + APK 下载。
- 数据保存在应用本地目录。

## 6. 服务器

- 原生部署。
- systemd 管理 yumeCore 服务进程。
- 数据目录放 `/srv/yumefriend/data`。
- token 用环境变量配置。
- 前面放 Nginx / Caddy 做 HTTPS。
- 服务器负责同步和附件存储。
- 局域网同步继续保留。

## 7. CI

- GitHub Actions。
- Python：ruff + pytest。
- Kotlin：Gradle + Kotlin Test。
- 前端：oxlint + Vitest + Playwright。
- 打标签触发正式构建。
