# yumeFriend 接口文档

## 1. 通用约定

- yumeCore 本机接口：`http://127.0.0.1:{core_port}/core/v1`
- 电脑端产品接口：`http://127.0.0.1:{port}/api/v1`
- 手机端接口：Kotlin 接口，不走 HTTP
- 服务器同步接口：`https://{server}/server-sync/v1`
- 请求和响应使用 JSON；文件上传用 `multipart/form-data`。
- ID 使用 UUID 字符串。
- 时间使用 UTC ISO8601；日程的 `date_local`、`time_local` 使用本地值。
- 数据库里带 `_json` 的字段，接口返回解析后的对象或数组。
- 对象字段与 `5.数据模型` 一致；`module_id` 见 `5.数据模型` 的 `1.1 模块 ID`。
- 列表返回 `{items, next_cursor}`；分页参数 `cursor`、`limit`。
- 电脑端产品接口不需要 token；对端接口使用 `X-YF-Peer-Token`；服务器同步使用 `X-YF-Server-Token`。

错误格式：

```json
{
  "error": {
    "code": "not_found",
    "message": "资源不存在"
  }
}
```

## 2. yumeCore 接口

yumeCore 是通用运行时，不提供业务接口。实体名、表、同步范围由模块清单定义。

### 2.1 本机 HTTP / WebSocket

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/modules` | 模块清单 |
| POST | `/read` | 通用读 |
| POST | `/write` | 通用写 |
| GET | `/events` | 事件列表，可按 `after` 拉取 |
| WS | `/ws` | 事件推送 |
| GET | `/devices` | 本机和已知设备 |
| POST | `/sync/discover` | 发现设备或产品 |
| GET | `/peers` | 已发现设备或产品 |
| POST | `/pair` | 发起配对 |
| POST | `/peers/{peer_id}/grant` | 模块授权 |
| POST | `/call` | 发起能力调用 |
| POST | `/sync/run` | 局域网或服务器同步 |
| GET | `/sync/conflicts` | 同步冲突 |

通用读：

```json
{
  "module_id": "chat",
  "entity": "messages",
  "filter": { "friend_id": "uuid" },
  "cursor": null,
  "limit": 50
}
```

通用写：

```json
{
  "module_id": "chat",
  "entity": "messages",
  "op": "create",
  "data": {}
}
```

`op` 取 `create` / `update` / `delete`。

配对：

```json
{
  "device_id": "uuid"
}
```

返回：

```json
{
  "peer_id": "uuid",
  "pair_secret": "secret"
}
```

能力调用：

```json
{
  "peer_id": "uuid",
  "module_id": "chat",
  "capability": "chat.send",
  "input": {}
}
```

返回 `{ "output": {} }`。

模块授权：

```json
{
  "module_id": "memory",
  "resource_id": null,
  "permission": "read"
}
```

同步：

```json
{
  "channel": "lan",
  "peer_id": "uuid",
  "direction": "both"
}
```

`channel` 取 `lan` / `server`；`direction` 取 `pull` / `push` / `both`。

yumeCore WebSocket 事件：`module.changed`、`sync.status`、`peer.found`、`sync.conflict`。

### 2.2 手机 Kotlin 接口

手机端直接调用同一组能力：

```kotlin
interface YumeCore {
    fun modules(): List<ModuleManifest>
    fun read(req: ReadRequest): ReadResult
    fun write(req: WriteRequest): WriteResult
    fun events(after: String?): Flow<CoreEvent>
    fun devices(): List<Device>
    fun peers(): List<Peer>
    fun pair(deviceId: String): PairResult
    fun grant(peerId: String, req: GrantRequest)
    fun call(req: CallRequest): CallResult
    fun sync(req: SyncRequest): SyncResult
}
```

方法名与上面的 HTTP 接口对应，请求和响应对象一致。

### 2.3 对端接口

对端接口基地址：`http://{lan_ip}:{core_port}/peer/v1`。除配对请求外都带 `X-YF-Peer-Token`。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/pair/request` | 配对请求 |
| POST | `/call` | 能力调用 |
| POST | `/pull` | 拉取变更 |
| POST | `/push` | 推送变更 |
| GET | `/assets` | 附件清单 |
| GET | `/assets/{sha256}` | 下载附件 |
| POST | `/assets/{sha256}` | 上传附件 |

配对请求：

```json
{
  "product_id": "yumeFriend",
  "device_id": "uuid",
  "protocol_version": 1
}
```

配对响应：

```json
{
  "peer_id": "uuid",
  "pair_secret": "secret"
}
```

能力调用：

```json
{
  "module_id": "chat",
  "capability": "chat.send",
  "input": {}
}
```

返回 `{ "output": {} }`。同步请求与响应见 `14.生态协作协议`。

### 2.4 服务器同步

服务器只做同步和附件存储，不跑模型、不跑语音。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/server-sync/v1/pull` | 拉取模块变更 |
| POST | `/server-sync/v1/push` | 推送模块变更 |
| GET | `/server-sync/v1/assets` | 附件清单 |
| GET | `/server-sync/v1/assets/{sha256}` | 下载附件 |
| POST | `/server-sync/v1/assets/{sha256}` | 上传附件 |

拉取：

```json
{
  "device_id": "uuid",
  "cursor": "……",
  "module_ids": ["chat", "memory", "schedule", "life"]
}
```

变更：

```json
{
  "module_id": "chat",
  "entity_type": "messages",
  "entity_id": "uuid",
  "updated_at": "2026-11-21T10:00:00Z",
  "data": {}
}
```

`module_id` 表示模块，`entity_type` 表示具体表；`entity_id` 规则见 `14.生态协作协议`。

推送：

```json
{
  "device_id": "uuid",
  "cursor": "……",
  "changes": [
    {
      "module_id": "chat",
      "entity_type": "messages",
      "entity_id": "uuid",
      "updated_at": "2026-11-21T10:00:00Z",
      "data": {}
    }
  ],
  "tombstones": [
    {
      "module_id": "chat",
      "entity_type": "messages",
      "entity_id": "uuid",
      "deleted_at": "2026-11-21T10:00:00Z"
    }
  ]
}
```

语音音频不进入服务器同步。

## 4. 手机端产品接口

Compose ↔ Kotlin 业务 / yumeCore。Kotlin 接口，不走 HTTP。

```kotlin
interface MobileApi {
    fun friends(): List<Friend>
    fun messages(friendId: String, cursor: String?): MessagePage
    fun sendMessage(friendId: String, text: String, assetIds: List<String>): SendResult
    fun sendMessageStream(friendId: String, text: String, assetIds: List<String>): Flow<ChatEvent>

    fun memories(friendId: String): List<Memory>
    fun addMemory(friendId: String, req: MemoryDraft): Memory
    fun updateMemory(memoryId: String, req: MemoryPatch): Memory
    fun deleteMemory(memoryId: String)

    fun schedules(friendId: String): List<Schedule>
    fun createSchedule(friendId: String, req: ScheduleDraft): Schedule
    fun updateSchedule(scheduleId: String, req: SchedulePatch): Schedule
    fun settleSchedule(scheduleId: String, reason: String): Schedule

    fun documents(friendId: String): List<Document>
    fun searchDocuments(friendId: String, query: String): List<DocumentHit>

    fun synthesize(text: String, voiceId: String?): Asset
    fun transcribe(assetId: String): Transcript

    fun settings(scope: String): List<Setting>
    fun theme(): Theme
    fun setTheme(theme: Theme)
}
```

请求和响应对象与 `5.数据模型` 一致。手机端首期只提供聊天、记忆、日程、语音、知识库、主题。

## 5. 流式与事件

聊天流：

```text
event: start
data: {"message": {}}

event: delta
data: {"text": "今"}

event: segment
data: {"index": 0, "text": "今天也辛苦了。", "mood": "温柔"}

event: end
data: {"message": {}}

event: error
data: {"code": "model_error", "message": "模型调用失败"}
```

事件格式：

```json
{
  "id": "event-uuid",
  "type": "message.created",
  "payload": {},
  "created_at": "2026-11-21T10:00:00Z"
}
```

## 6. 错误码

| 错误码 | 说明 |
|---|---|
| `bad_request` | 请求参数错误 |
| `validation_error` | 字段校验失败 |
| `not_found` | 资源不存在 |
| `conflict` | 数据冲突 |
| `sync_error` | 同步失败 |
| `model_error` | 模型调用失败 |
| `internal_error` | 内部错误 |
